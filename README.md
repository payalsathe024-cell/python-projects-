# 🏨 Hotel Management System

A simple **Hotel Management System** developed using **Python and Tkinter**. This desktop application allows users to enter customer details, select a room, calculate the hotel bill, check out customers, and clear the entered information.

## 📌 Features

* 👤 Enter customer name
* 📞 Enter phone number
* 🛏️ Select room number
* 🏠 Select room type
* 📅 Enter number of days
* 💰 Enter price per day
* 🧾 Calculate total hotel bill
* ✅ Customer checkout
* 🧹 Clear all data
* ❌ Exit the application
* ⚠️ Error handling for invalid number input

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **Messagebox**

## 🖥️ How It Works

1. Enter the customer's name and phone number.
2. Select a room number.
3. Enter the number of days.
4. Select the room type.
5. Enter the price per day.
6. Click **Calculate Bill**.
7. The application calculates:

```text
Total Bill = Number of Days × Price Per Day
```

8. Click **Check Out** after completing the customer's stay.
